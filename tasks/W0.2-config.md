## Caller options & resolution

Enum tokens exactly as written (§6.1 table):

- `ScopePolicy`: `user_content` (default) | `user_and_tools` | `all_messages`* | `explicit_paths`*
  (*reserved per §10 — v1 must reject them in resolution)
- `MarkerStyle`: `auto` (default) | `ascii` | `unicode`

`RawOptions` = six `Option` fields: `scope_policy`, `min_group_size: Option<u32>`,
`normalize_ws`, `template_dedup`, `marker_style`, `reversible`.

`resolve(&RawOptions) -> Result<ResolvedOptions, ResolveError>`:

- `scope_policy`: `None` ⇒ `user_content`; reserved variant ⇒ `Err(UnsupportedScopePolicy)`
- `min_group_size`: `None | Some(0)` ⇒ 3 (§6.2 "0 => server default"); `Some(1)` ⇒
  `Err(MinGroupSizeBelowTwo)`; `Some(n ≥ 2)` ⇒ n
- `normalize_ws` ⇒ true; `template_dedup` ⇒ true; `marker_style` ⇒ `auto`; `reversible` ⇒ false

## options_echo (§6.2 `Stats.options_echo`)

Canonical compact JSON, fixed field order, hand-rolled via `format!` (no serde):
order = scope_policy, min_group_size, normalize_ws, template_dedup, marker_style, reversible.
Golden literal a unit test must pin byte-for-byte:

```
{"scope_policy":"user_content","min_group_size":3,"normalize_ws":true,"template_dedup":true,"marker_style":"auto","reversible":false}
```

## Required tests (exit criterion: defaults pinned by unit tests)

- default resolve == expected struct AND echo == golden literal
- min_group_size: `Some(0)`→3, `Some(1)`→Err, `Some(2)`→2, `Some(u32::MAX)`→Ok
- explicit overrides flow through; both implemented policies resolve; both reserved rejected
- `parse(as_str(x)) == Some(x)` for every variant of both enums; garbage token → `None`
- consts asserted against literal integers (drift guard)
